실습 1

Gemini Notebook — 내 자료에만 근거해 답하는 AI

오늘의 자료 전공기초 교재 한 단원, 실험 매뉴얼 (공학은 제품 데이터시트 1~2종 추가 가능)
notebook.google.com → [새 노트북] → [소스 추가]로 자료를 올린 뒤 시작
01.기본

개념 정리표 만들기

업로드한 자료로 '개념 | 정의 | 관련 식·단위 | 실험에서의 역할 | 출처' 표를 만들어 줘. 자료에 없는 내용은 쓰지 말고, 모든 칸에 인용 번호를 붙여 줘.
02.기본

스튜디오: 퀴즈·오디오 오버뷰

클릭 실습

스튜디오에서 [퀴즈]로 시험 대비 문제를 풀거나 [오디오 오버뷰]로 핵심을 대화로 듣기. 틀린 문제는 인용 번호로 원문 확인

03.도전

헷갈리는 개념·단위 찾기

이 자료에서 학생들이 자주 헷갈릴 만한 개념이나 단위 2가지를 골라, 자료 속 근거와 함께 차이를 설명해 줘.

실습 2

Gem — 실험 레포트 점검 조교

gemini.google.com → 왼쪽 메뉴 [Gem 관리자] → [새 Gem] → 이름에 '실험 레포트 점검 조교' 입력 → [지침] 칸에 붙여넣기 → [저장]
01.기본

지침 붙여넣기

  • P너는 이공계 기초 실험 수업의 친절하지만 꼼꼼한 조교야.
  • A내 가설·실험 계획이나 레포트 문단을 읽고 변인(독립·종속·통제)과 대조군, 빠진 실험 조건, 단위 실수, 근거 없는 결론을 찾아 줘.
  • R1~2학년도 이해할 수 있게 용어를 풀어서 설명해 줘.
  • T실험 레포트 준비 중이야. 레포트를 대신 써 주거나 실험 수치를 지어내 채워 달라는 요청은 거절하고, 내가 직접 고칠 수 있게 어디가 왜 아쉬운지만 짚어 줘.
  • S① 잘된 점 1개 ② 고칠 점 3개(이유 포함) ③ 변인·단위 점검표 ④ 스스로 확인할 질문 2개 순서로 답해 줘.

도전 A(작업)와 T(맥락)를 내 과제에 맞게 고쳐서 다시 테스트

02.기본

테스트 프롬프트

물 온도가 높을수록 설탕이 빨리 녹는지 20℃, 40℃, 60℃에서 실험했어. 60℃ 결과가 예상보다 느렸는데 레포트에 '측정 실수 때문'이라고만 썼어. 빠진 게 뭐야?
03.

검토하기

  • S(형식)대로 답하는가?
  • T(맥락)의 금지 사항을 지키는가?
  • 다음 질문에서도 지침이 유지되는가?

Google은 Gem을 '스킬'로 순차 전환 중. 학교 계정은 2027년 6월까지 Gem 사용 가능하며, 같은 지침을 스킬에 그대로 붙여넣어도 됨.

실습 3

Canvas — 문서·웹앱을 함께 만드는 공간

Gemini 입력창 [도구] → [Canvas] 선택 후 01 프롬프트 입력. 02는 오른쪽 문서에서 해당 문단을 드래그한 다음 붙여넣기
01.기본

실험 레포트 틀

Canvas에서 실험 레포트 틀을 만들어 줘. 목차는 1. 실험 목적 2. 이론(노트북 정리표 반영) 3. 실험 방법(변인 점검표 포함) 4. 결과 5. 오차 분석 6. 결론. 결과 수치 자리는 [데이터 입력]으로 비워 둬.
02.기본

선택 부분만 고치기

'5. 오차 분석' 문단을 드래그한 뒤

오차 원인을 '계통 오차 / 우연 오차'로 나눠 쓸 수 있는 표 형식으로 바꿔 줘.
03.도전

퀴즈 또는 계산기 만들기

노트북 정리표의 개념으로 10문항 인터랙티브 퀴즈를 Canvas로 만들어 줘. 틀리면 해설이 보이게 해 줘. (또는: 레포트에 나오는 단위를 바꿔 주는 웹 계산기를 만들어 줘.)
